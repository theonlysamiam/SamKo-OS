# Skill: publish-schedule

The recipe the social-media agent (or Sam) follows to schedule an approved batch of posts. Nothing here creates or approves content — it only ships what's already signed off.

## Inputs to gather first
- The approved posts (final graphics + captions). Confirm each one is approved by Sam or Jon. If unsure, stop.
- Platforms for each post (Instagram, TikTok, Facebook, LinkedIn).
- The schedule (dates/times, or a cadence like "3×/week for 2 weeks").
- Which publisher: Metricool or Blotato.

If anything is missing or an approval is unclear, ask Sam one sharp question rather than guessing.

## Steps
1. **Open the publisher** and the right connected account(s).
2. **Load each post:** upload the graphic, paste the exact approved caption, set the platform(s). Don't rewrite captions.
3. **Schedule** each post at its date/time. Space them to the agreed cadence.
4. **Verify the queue:** read back the full schedule — post, platform, date/time — and check nothing is doubled or missing.
5. **Log it:** save a simple list of what's scheduled so Sam can see the plan.

## Reporting (after the batch runs)
Two weeks in, pull reach/engagement/follower change per post, and write a 5-line report: top post, weakest post, one trend, one recommendation (continue / pivot / add).

## Gate & output
This skill assumes content already passed the human approval gate — never schedule anything unapproved. Hand Sam the confirmed schedule (or the report) and his next floor.
